# LivGro Vision Foundation — Website Redesign

First visual draft of the About / Who We Are experience.

## Stack
HTML5, Bootstrap 5, Bootstrap Icons, LESS and vanilla JavaScript.

## Direction
Transparent-to-white sticky header, compact mobile offcanvas navigation, full-height hero, editorial storytelling, organic/asymmetric image masks, shaped section transitions, restrained parallax and shared enquiry modal. Repetitive Bootstrap-card layouts are intentionally avoided.

## Structure
- `index.html` — first About page draft
- `less/style.less` — LESS source
- `css/style.css` — browser-ready stylesheet
- `js/main.js` — scroll header and reveal interactions

Remote Unsplash imagery is placeholder-only and will be replaced by final LivGro assets.
